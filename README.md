# 미래 소득 현재가치 계산기 · 똑재TV

은퇴할 때까지 앞으로 벌 돈을 지금 가치(인적자본)로 바꾸고, 금융자산과 합친 생애 총자산과 금융자산이 인적자본을 앞지르는 나이를 보여 주는 계산기.

- 사이트: https://ttokjaetv.github.io/human-capital/
- 계산: 소득은 매달 말 수령으로 보고 할인(월 할인율 = (1+연)^(1/12) − 1), 수입은 수입 증가율·생활비는 물가만큼 증가, 금융자산은 할인율과 같은 수익률
- 경제적 자유 계산기(freedom)와 URL 파라미터로 값을 주고받음

## 수정하는 법
`src/`를 고친 뒤 `python src/build.py` → `index.html` 생성. 엔진 검증은 `cd src && node test.js`.
